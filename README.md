# Sistema de Controle Financeiro Pessoal

Projeto desenvolvido para a disciplina de Programação Orientada a Objetos.

O sistema tem como objetivo realizar o controle básico de finanças pessoais, permitindo o registro de receitas e despesas, organização por categorias e consulta da situação financeira.

## Integrantes

- Vinícius Almeida

## Funcionalidades previstas

- Cadastro de receitas
- Cadastro de despesas
- Organização das transações por categoria
- Listagem das transações
- Cálculo do total de receitas
- Cálculo do total de despesas
- Cálculo do saldo
- Verificação da situação financeira
