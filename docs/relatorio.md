# Sistema de Controle Financeiro Pessoal

## 1. Descrição

O projeto consiste no desenvolvimento de um Sistema de Controle Financeiro Pessoal utilizando a linguagem Python e os conceitos de Programação Orientada a Objetos.

O sistema permitirá registrar receitas e despesas, classificá-las por categorias e consultar informações como total de receitas, total de despesas, saldo atual e situação financeira.

## 2. Justificativa

O controle financeiro está presente no cotidiano das pessoas e envolve diferentes tipos de movimentações financeiras.

A escolha desse tema permite representar de forma prática conceitos estudados na disciplina de Programação Orientada a Objetos.

Receitas e despesas possuem características em comum, como descrição, valor, data e categoria, porém apresentam comportamentos diferentes em relação ao saldo financeiro.

Dessa forma, o projeto possibilita a aplicação de conceitos como abstração, encapsulamento, herança, polimorfismo, relacionamento entre classes e classes abstratas.

## 3. Funcionalidades

- Cadastrar receitas;
- Cadastrar despesas;
- Associar categorias às transações;
- Listar as transações cadastradas;
- Calcular o total de receitas;
- Calcular o total de despesas;
- Calcular o saldo atual;
- Verificar a situação financeira.

## 6. Bibliotecas

Nesta etapa do projeto serão utilizadas apenas bibliotecas pertencentes à biblioteca padrão do Python.

Será utilizado o módulo `abc` para implementação da classe abstrata `Transacao` e o módulo `datetime` para representação da data das transações.

Não serão utilizadas bibliotecas externas nesta etapa.
