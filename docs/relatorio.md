Sistema desenvolvido em Python para gerenciamento básico das finanças pessoais, permitindo o registro e acompanhamento de receitas e despesas organizadas por categorias.
Justificativa
Controle financeiro é um problema cotidiano e permite representar de maneira clara diversos conceitos de programação orientada a objetos. Receitas e despesas possuem características comuns, mas comportamentos diferentes, possibilitando a aplicação prática de abstração, encapsulamento, herança, polimorfismo e classes abstratas.
Funcionalidades
Cadastro de receitas
Cadastro de despesas
Cadastro/utilização de categorias
Listagem das movimentações
Cálculo de receitas
Cálculo de despesas
Cálculo do saldo
Consulta das movimentações
